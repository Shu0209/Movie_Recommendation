# 🎬 CineMatch - Movie Recommender System

A **beautiful and fast** movie recommendation web app built with **FastAPI** backend and **Streamlit** frontend.

---

## ✨ Features

- Content-based movie recommendations using **TF-IDF**
- Full movie details from **OMDB API** (posters, plot, cast, ratings, etc.)
- Search movies and TV series
- Two recommendation modes (Bundle + TF-IDF Only)
- Clean and modern user interface
- FastAPI REST API with multiple endpoints

---

## 🛠 Tech Stack

| Component     | Technology                  |
|---------------|-----------------------------|
| Backend       | FastAPI + Python            |
| Frontend      | Streamlit                   |
| Recommendation| TF-IDF (scikit-learn)       |
| API           | OMDB API                    |
| Data          | Pandas + Pickle             |
